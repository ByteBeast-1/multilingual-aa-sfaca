# 🌐 Complete Project Ideology & Architectural Specification
## Script-Family-Aware Contrastive Adaptation (SFA-CA) for Multilingual Authorship Attribution & Forensic Detection of AI-Generated Text

---

## 1. Executive Summary

With the explosive growth of Large Language Models (LLMs) such as GPT-4, LLaMA-3, Mistral, and Vicuna, machine-generated text has become nearly indistinguishable from human writing across dozens of languages. This introduces two critical research and forensic challenges:
1. **AI Text Detection (Binary):** Distinguishing whether a text was authored by a Human or generated by a Machine.
2. **Authorship Attribution (Multi-Class Provenance):** Identifying the *exact* LLM generator model (among a candidate set of 7 LLMs) responsible for producing the text.

The primary baseline study in this domain — *La Cava et al. (ACL 2026), "Authorship Attribution in Multilingual Machine-Generated Texts"* — evaluated attribution methods across 18 languages and demonstrated a fundamental bottleneck: **Attribution performance collapses when transferring across different writing scripts or language families** (e.g., a model trained on Latin-script text performs poorly on Cyrillic, Arabic, Greek, or Hanzi scripts).

This project introduces **Script-Family-Aware Contrastive Adaptation (SFA-CA)**, a novel parameter-efficient framework that solves the cross-script collapse problem. By freezing a multilingual transformer backbone (`XLM-RoBERTa-large`) and training lightweight Low-Rank Adapters (LoRA) per script-family cluster using a dual-axis supervised contrastive loss, SFA-CA enables high-accuracy in-cluster attribution and zero-shot cross-script generalization.

### 2.1 The Cross-Script Collapse Problem
Existing multilingual models rely on shared subword tokenizers (e.g., SentencePiece). However:
- **Surface Script Dominance:** Standard fine-tuning causes the model to overfit to surface-level token n-grams of a specific script (e.g., English/Latin alphabet) rather than deep stylistic author signatures (syntactic structure, punctuation distributions, vocabulary entropy).
- **Distributional Mismatch:** When evaluated on non-Latin scripts (Cyrillic, Arabic, Greek, CJK), standard transformer representations degrade sharply.

### 2.2 The SFA-CA Paradigm Shift
Instead of training one monolithic model for all languages, SFA-CA decouples general multilingual knowledge from script-family stylistic transformations:
1. **Frozen Multilingual Foundation:** The backbone (`XLM-RoBERTa-large`, 550M parameters) remains 100% frozen, preserving pre-trained multilingual embeddings without catastrophic forgetting.
2. **Script-Family Clusters:** Languages are grouped into 5 typological script clusters:
   - **Latin Cluster:** English, Spanish, German, French, Dutch, Portuguese, Romanian, Czech, Polish, etc.
   - **Cyrillic Cluster:** Russian, Ukrainian, Bulgarian, Macedonian, Serbian.
   - **Hellenic Cluster:** Greek.
   - **Semitic Cluster:** Arabic, Persian, Urdu.
   - **CJK / Hanzi Cluster:** Chinese, Japanese, Korean.
3. **PEFT / LoRA Adapter Wiring:** Small Low-Rank Adaptation (LoRA) matrices ($A$ and $B$) are inserted into the attention projections (`query`, `value`). Only **~0.2% of total model parameters** are trained per cluster.
4. **Supervised Contrastive Objective:** A specialized loss function:
   - **Pulls together** representations of texts from the same generator even across different scripts.
   - **Pushes apart** representations of different generators within the same script cluster.

## 3. Mathematical & Architectural Specification

### 3.1 LoRA Parameter-Efficient Adaptation
For a pre-trained frozen weight matrix $W_0 \in \mathbb{R}^{d \times k}$ in the attention layer, LoRA parameterizes the weight update $\Delta W$ using two low-rank matrices $A \in \mathbb{R}^{r \times k}$ and $B \in \mathbb{R}^{d \times r}$ with rank $r \ll \min(d, k)$:

$$h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} B A x$$

For each script cluster $c \in \{\text{Latin}, \text{Cyrillic}, \text{Greek}, \text{Arabic}, \text{Hanzi}\}$, a dedicated adapter $(A_c, B_c)$ is assigned. At inference time on text from script $c$, adapter $(A_c, B_c)$ is dynamically activated.

### 3.2 Supervised Contrastive Loss (SFACA Loss)
Let $z_i = \text{normalize}(f(x_i))$ be the normalized embedding of text sample $x_i$ produced by the active SFA-CA encoder. The contrastive loss for a batch is formulated as:

$$\mathcal{L}_{\text{contrastive}} = \sum_{i \in I} \frac{-1}{|P(i)|} \sum_{p \in P(i)} \log \frac{\exp(z_i \cdot z_p / \tau)}{\sum_{a \in A(i)} \exp(z_i \cdot z_a / \tau)}$$

Where:
- $P(i)$ is the set of positive samples in the batch sharing the **same author/generator label** as $x_i$.
- $A(i)$ is the set of all samples excluding $x_i$.
- $\tau$ is the temperature hyperparameter ($\tau = 0.07$).

The total objective combines Cross-Entropy classification loss $\mathcal{L}_{\text{CE}}$ and SFACA contrastive loss with weight $\lambda = 0.5$:

$$\mathcal{L}_{\text{total}} = (1 - \lambda) \mathcal{L}_{\text{CE}} + \lambda \mathcal{L}_{\text{contrastive}}$$

## 4. Real-World Robustness: Math & Notation Sanitizer

### 4.1 False-Positive AI Detection on Technical Text
A major real-world flaw of existing AI text detectors (e.g., Turnitin, GPTZero, CopyLeaks) is that they **wrongly flag human-written academic and scientific papers as AI-generated**. This occurs because LaTeX math equations ($\sum_{i=1}^n x_i$, $\int_0^\infty e^{-x^2} dx$), code snippets (` ```python...``` `), and chemical formulas produce unnatural token perplexity spikes.

### 4.2 Notation-Aware Sanitization & Confidence Calibration
SFA-CA includes a built-in **Notation Sanitizer and Calibrator (`src/sanitizer.py`)**:
1. **Regex AST Extraction:** Automatically strips raw LaTeX equations (`$...$`, `\begin{equation}...\end{equation}`) and markdown code snippets before transformer attribution.
2. **Notation Density Index (NDI):** Calculates the fraction of text consisting of mathematical/code notation:
   $$\text{NDI} = \frac{\text{Character Count of Extracted Math \& Code}}{\text{Total Document Character Count}}$$
3. **Dynamic Confidence Calibration:** When NDI is high ($\text{NDI} > 0.05$), raw Softmax probabilities are recalibrated to boost human class confidence, preventing false-positive AI flags on technical research papers.
