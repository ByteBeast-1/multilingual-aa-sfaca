# Full-pipeline evaluation (real adapters, calibrated)

Generated by `python scripts/eval_pipeline.py` after `python scripts/calibrate.py`. Hardware: RTX 4050 Laptop 6 GB.
Adapters: `results/runs/<cluster>_seed42` (one seed, 3 epochs, length 128). Calibration and window size fitted on the validation split only.

Documents come from the held-out TEST split (length > 400 chars), up to 25 human + 25 AI per cluster, scored end to end
(sentence split -> 64-token windows -> adapter -> calibration -> aggregate). "Correct" = AI% >= 50 for AI documents, < 50 for human.

Hanzi has only 4 human documents above the length filter (Chinese needs fewer characters), so its accuracy is not reliable.

Mixed documents (English; 3 human + 3 GPT-3.5 paragraphs, 10 documents), sentence-level AI detection at threshold 0.5:
precision 0.827, recall 1.000, F1 0.906 (tp 259, fp 54, fn 0, tn 295).

Per-cluster test macro-F1 on the 8-class task (single seed, from `results/runs/*/metrics.json`):
greek 0.814, arabic 0.863, hanzi 0.597, cyrillic 0.731, latin 0.796.

Caveats: samples are small (25 per class), single seed, news-domain text, generators from 2023.
Text from newer models (GPT-4o, Claude, Gemini) is outside the training distribution.
